# IPS114 屏幕与赛道像素对应关系

## 一、基本参数

| 参数 | 值 |
|------|:---:|
| 摄像头分辨率 | 188 × 120（列 × 行） |
| IPS114 屏幕分辨率 | 200 × 114（宽 × 高） |
| 图像存储格式 | `bin_image[120][188]`，行0=远处，行119=近处 |

## 二、摄像头坐标系

```
摄像头坐标（俯视赛道）：

列0                                              列187
 ┃                                                 ┃
 ┃  行0（最远处，赛道最窄）                            ┃
 ┃  行1                                              ┃
 ┃  行2                                              ┃
 ┃  ...                                             ┃
 ┃  行59（图像中间）                                  ┃
 ┃  ...                                             ┃
 ┃  行118                                           ┃
 ┃  行119（最近处，赛道最宽）                          ┃
 ┃                                                 ┃
```

**关键对应关系：**
- **行0** = 摄像头看到的**最远处**（赛道看起来最窄）
- **行119** = 摄像头看到的**最近处**（就在车头下方）
- **列0** = 图像**最左边**
- **列187** = 图像**最右边**
- **列94** = 图像**正中间**

## 三、IPS114 屏幕显示映射

IPS114 是 200×114 像素，摄像头是 188×120。

你代码中的显示方式（`cpu0_main.c`）：

```c
// 显示二值化图像
for (int i = 0; i < ROW; i++)      // 行0~119
{
    for (int j = 0; j < COL; j++)  // 列0~187
    {
        if (bin_image[i][j] == WHITE)
            ips114_draw_point(j, i, WHITE);  // 直接对应
        else
            ips114_draw_point(j, i, BLACK);
    }
}
```

**映射关系：**
```
摄像头 bin_image[i][j]  →  IPS114 屏幕坐标 (j, i)
                                 x轴=列号
                                 y轴=行号

bin_image[0][0]   →  屏幕左上角 (0, 0)    ← 远处最左边
bin_image[0][94]  →  屏幕顶部中间 (94, 0)  ← 远处正中间
bin_image[119][0]  →  屏幕左下角 (0, 119)  ← 近处最左边
bin_image[119][94] →  屏幕底部中间 (94, 119) ← 近处正中间（车头正下方）
```

## 五、赛道边界对应

`search_line()` 找到的边界：

```
行号    l_border    r_border    中线mid_line    含义
  5       85          95          90           远处赛道窄，边界靠近中间
  30      75         105          90           中距离
  60      65         115          90           较近
  90      55         125          90           近处赛道宽
  119     45         135          90           最近处最宽
```

**在屏幕上看：**
```
行5:   l=85  r=95   ← 左右边界很靠近（赛道窄）
行60:  l=65  r=115  ← 左右边界分开一些
行119: l=45  r=135  ← 左右边界分得很开（赛道宽）
```

## 六、直角弯在屏幕上的样子

```
直角右弯：

行0:   l=90  r=94      ← 远处直道（窄）
行10:  l=88  r=96      ← 还是直道
行20:  l=85  r=100     ← 开始变宽（弯道入口）
行30:  l=80  r=120     ← 明显变宽（弯道展开）
行40:  l=75  r=140     ← 右侧大幅展开（右转方向）
行50:  l=70  r=115     ← 过了弯道，回到直道
行60:  l=65  r=115     ← 直道
...

在屏幕上看到：
┌──────────────────────┐
│        ██            │  ← 行5：窄直道
│        ██            │
│       ████           │  ← 行20：开始变宽
│      ██████          │  ← 行30：弯道展开
│    ██████████        │  ← 行40：右侧大幅展开（右转方向）
│      ██████          │  ← 行50：回到直道

```

## 八、调试时如何对应

在屏幕上看到异常时，用以下方法定位：

```
方法1：看行号
  异常出现在屏幕上方 → 对应图像行0~30（远处）
  异常出现在屏幕下方 → 对应图像行80~119（近处）

方法2：看列号
  异常出现在屏幕左侧 → 对应图像列0~60（左边）
  异常出现在屏幕右侧 → 对应图像列128~187（右边）
  异常在屏幕中间      → 对应图像列60~128（赛道区域）

方法3：看边界值
  printf("行%d: l=%d r=%d w=%d mid=%d\n", i, l_border[i], r_border[i],
         r_border[i]-l_border[i], mid_line[i]);
  在串口看具体数值，对照上面的表格判断
```
