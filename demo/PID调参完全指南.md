# 智能车PID调参完全指南（强磁电机版 V5 最终版）

---

## 一、你的代码中各变量的含义

### 速度环（内环）

| 变量 | 位置 | 含义 |
|------|------|------|
| `base_speed` | control.c:47, 值=150 | **目标速度**（你想让车跑多快） |
| `actual_speed` | control.c:88 | **实际给定速度**（经过软启动/减速后） |
| `l_speed_output` | control.c:111 | **左轮目标速度** = actual_speed + steer |
| `r_speed_output` | control.c:112 | **右轮目标速度** = actual_speed - steer |
| `l_now_vel` | encoder.c:30 | **左轮实际速度**（编码器测量） |
| `r_now_vel` | encoder.c:31 | **右轮实际速度**（编码器测量） |
| `error_left` | control.c:117 | **左轮速度误差** = 目标 - 实际 |
| `output_left` | control.c:121 | **左轮PWM输出**（PID计算结果） |
| `pid_left.Kp` | control.c:22, 值=4.0 | **速度比例增益** |
| `pid_left.Ki` | control.c:23, 值=0.2 | **速度积分增益** |
| `pid_left.Kd` | control.c:24, 值=0 | **速度微分增益** |

### 转向环（外环）

| 变量 | 位置 | 含义 |
|------|------|------|
| `image_err` | image.c:964 | **图像误差**（赛道中线偏离图像中心的距离） |
| `steer_pwm_out` | control.c:100 | **转向输出**（给左右轮的差速量） |
| `steer_pid.kp` | control.c:18, 值=25 | **转向比例增益** |
| `steer_pid.kp2` | control.c:19, 值=1.0 | **转向非线性比例** |
| `steer_pid.kd` | control.c:20, 值=2.0 | **转向微分增益** |
| `steer_pid.gkd` | control.c:21, 值=35 | **陀螺仪阻尼增益** |

### 控制链路

```
image_err → 转向PID → steer_pwm_out
                          ↓
左轮目标 = actual_speed + steer_pwm_out → 速度PID → 左轮PWM
右轮目标 = actual_speed - steer_pwm_out → 速度PID → 右轮PWM
```

## 二、调参前的准备

### 必须确认的事情

```
□ 电机能正转和反转
□ 编码器能读数（串口打印 l_encoder/r_encoder 值在变化）
□ 陀螺仪能读数（串口打印 gyro_z 在变化）
□ 摄像头能看到赛道（IPS114 显示二值化图像正常）
□ 电池电量充足
```

### 安全措施

```
□ 车放在地上（不要悬空）
□ 手随时准备抓住车
□ base_speed 先设为 0
□ 转向PID参数全设为 0（禁用转向）
```

## 三、调参步骤（一步一步来）

### 第0步：地推测试 — 确认Kp范围

```
目的：用手推车感受电机阻力，快速判断Kp是否在工作

操作：
  1. pid_left.Kp = 0, pid_left.Ki = 0, pid_left.Kd = 0
  2. pid_right.Kp = 0, pid_right.Ki = 0, pid_right.Kd = 0
  3. steer_pid.kp = 0, steer_pid.kp2 = 0, steer_pid.kd = 0, steer_pid.gkd = 0
  4. base_speed = 0
  5. 编译烧录

  6. 把车放在地上（轮胎着地）
  7. 用手慢慢推车
  8. 感受阻力

观察并记录：
  Kp=0  → 没阻力（PID没工作，正常）
  Kp=4  → 没感觉（太小）
  Kp=12 → 没感觉（还是太小，强磁电机需要更大）
  Kp=20 → 轻微阻力
  Kp=30 → 明显阻力
  Kp=40 → 有阻力，能推动 ✅
  Kp=43 → 有阻力，放开后不自转 ✅✅
  Kp=45 → 后轮离地会自转（略大）
  Kp=50 → 自己转（太大）

结论：Kp = 40~43（你的强磁电机实测结果）
```

### 第1步：速度环只开P

```
目的：让车能加速到目标速度

操作：
  pid_left.Kp  = 40      ← 地推测试确定的值
  pid_left.Ki  = 0        ← 关掉积分
  pid_left.Kd  = 0        ← 关掉微分
  pid_right.Kp = 40
  pid_right.Ki = 0
  pid_right.Kd = 0
  base_speed = 80          ← 低速开始
  转向PID全部设为0（禁用转向）

  编译烧录，把车放在直道上，按start启动

观察：
  车能加速吗？
  加速到多少停住了？（比如到了60就不再涨了）
  加速过程平滑吗？有没有抖动？

判断：
  能到80且稳定 → Kp合适 ✅ → 进入第2步
  到不了80（比如只到60）→ Kp偏小 → 加大到45试试
  加速时来回抖 → Kp太大 → 减小到35试试
```

### 第2步：速度环加I

```
目的：消除稳态误差（让车精确达到目标速度）

操作：
  pid_left.Kp  = 40      ← 保持第1步的值
  pid_left.Ki  = 0.2     ← 从0.2开始
  pid_left.Kd  = 0
  pid_right.Kp = 40
  pid_right.Ki = 0.2
  pid_right.Kd = 0
  base_speed = 80

  编译烧录，跑直道

观察：
  现在能精确到80了吗？
  加速时有没有猛冲一下？
  有没有低频晃动（每隔几秒摆一下）？

判断：
  能精确到80，没有猛冲 → Ki合适 ✅ → 进入第3步
  还是到不了80 → Ki偏小 → 加大到0.3
  加速时猛冲一下 → Ki太大 → 减小到0.1
  低频晃动 → Ki太大 → 减小

  ⚠️ 强磁电机注意：Ki太大 → 电机突然猛转 → 打滑！
  从0.2开始慢慢加，每次加0.1
```

### 第3步：速度环加D

```
目的：让加减速更平滑

操作：
  pid_left.Kp  = 40
  pid_left.Ki  = 0.2     ← 保持第2步的值
  pid_left.Kd  = 0.5     ← 从0.5开始
  pid_right.Kp = 40
  pid_right.Ki = 0.2
  pid_right.Kd = 0.5
  base_speed = 80

  编译烧录，跑直道

观察：
  加减速过程更平滑了吗？
  有没有高频抖动（快速的嗡嗡声）？

判断：
  加减速更平滑 → Kd合适 ✅ → 速度环调完
  高频抖动/嗡嗡叫 → Kd太大（放大了编码器噪声）→ 减小到0.3
  减速时冲过头 → Kd太小 → 加大到1.0
```

### 第4步：提速测试

```
目的：验证不同速度下的稳定性

操作：
  保持第3步调好的 Kp/Ki/Kd
  逐步加大 base_speed：
    80 → 跑一圈，记录效果
    100 → 跑一圈，记录效果
    120 → 跑一圈，记录效果
    150 → 跑一圈，记录效果

观察：
  每个速度下：
    直道稳不稳？
    有没有摆动？
    加速/减速平不平滑？

  如果某个速度不稳定 → 可能需要针对那个速度段微调参数
```

### 第5步：恢复转向环，只开P

```
目的：开始调转向

操作：
  速度环参数保持第3步的值不变
  steer_pid.kp  = 25      ← 恢复转向P
  steer_pid.kp2 = 0        ← 关掉非线性项
  steer_pid.kd  = 0        ← 关掉微分
  steer_pid.gkd = 0        ← 关掉陀螺仪
  base_speed = 80

  编译烧录，跑包含弯道的路线

观察：
  直道上稳不稳？有没有左右摆动？
  弯道能不能跟住？

判断：
  直道稳，弯道能跟 → kp合适 ✅
  直道大幅摆动 → kp太大 → 减小到20
  直道稳但弯道跟不住 → kp太小 → 加大到30
```

### 第6步：转向环加kp2（非线性项）

```
目的：让急弯时转向更有力

操作：
  steer_pid.kp  = 25
  steer_pid.kp2 = 1.0     ← 开启非线性项
  steer_pid.kd  = 0
  steer_pid.gkd = 0

  跑弯道路线

观察：
  急弯时转弯更有力了吗？
  直道上有没有受影响？

判断：
  急弯响应更快 → kp2合适 ✅
  直道也出现大幅偏转 → kp2太大 → 减小到0.5

  ⚠️ 强磁电机注意：kp2是误差的平方项，大误差时输出猛增
  强磁电机响应本身就猛，kp2不要太大！
```

### 第7步：转向环加kd（微分阻尼）

```
目的：抑制转弯后的抖动

操作：
  steer_pid.kp  = 25
  steer_pid.kp2 = 1.0
  steer_pid.kd  = 2.0     ← 开启微分
  steer_pid.gkd = 0

  跑弯道路线

观察：
  转弯后回正更平滑了吗？
  有没有抖动？

判断：
  转弯后平滑回正 → kd合适 ✅
  转弯后猛抖一下 → kd太大 → 减小到1.0
  转弯后回正很慢 → kd太小 → 加大到3.0
```

### 第8步：转向环加gkd（陀螺仪阻尼）

```
目的：高速时更稳定

操作：
  steer_pid.kp  = 25
  steer_pid.kp2 = 1.0
  steer_pid.kd  = 2.0
  steer_pid.gkd = 35      ← 开启陀螺仪

  全速跑（base_speed=150）

观察：
  高速时车更稳了吗？
  弯道时有没有反应变迟钝？

判断：
  高速更稳 → gkd合适 ✅
  弯道反应迟钝（转不过来）→ gkd太大 → 减小到25
  高速还是晃 → gkd太小 → 加大到45
```

### 第9步：联合测试

```
目的：直道+弯道+路口一起跑

操作：
  所有参数保持上面调好的值
  跑完整路线（包含直道、弯道、直角弯）

观察：
  直道稳不稳？
  弯道能不能过？
  直角弯能不能转？

如果直角弯冲出去 → 检查减速功能是否生效
如果直道摆动 → kp减小或kd加大
如果弯道跟不上 → kp加大或gkd减小
```

### 第10步：直角弯测试

```
确认：
  1. control.c 中的减速代码是否生效
     （node_state == NODE_DETECTED/TURNING 且 turn_dir == LEFT/RIGHT 时减速）
  2. 减速比 TURN_SPEED_RATIO = 0.5 是否合适
  3. 转弯容差 20度是否合适（太大→提前退出，太小→转不够）

观察：
  直角弯能转过来吗？
  转弯时速度降到多少了？
  转够90度才退出吗？

如果还是冲出去：
  → TURN_SPEED_RATIO 从0.5改到0.4（减速更多）
  → 或者kd加大（转弯时更强阻尼）
  → 或者缩小转弯容差（20→15→10度）
```

### 第11步：加转向积分项

```
目的：消除转弯时的持续偏差

操作：
  在 Steer_Pid 结构体中加 ki 和 error_integral
  steer_pid.ki = 0.5（从小开始）

  跑弯道

观察：
  转弯时角度够了吗？
  有没有低频摆动？

判断：
  转弯角度够了 → ki合适 ✅
  低频摆动 → ki太大 → 减小到0.2
  还是转不够 → ki太小 → 加大到1.0
```

### 第12步：分段PID（直道/弯道不同参数）

```
目的：直道追求速度，弯道追求稳定

操作：在 steer_pid_calc 中根据 error 大小切换参数

  if (fabsf(image_error) < 20)
      kp=25, kd=2.0, gkd=35     // 直道参数
  else
      kp=35, kd=4.0, gkd=25     // 弯道参数（kp大+kd大+gkd小）

  跑完整路线测试
```

## 五、强磁电机专项注意

| 事项 | 说明 |
|------|------|
| Kp从地推确定 | 你的实测：Kp=40~43 |
| Ki从小开始 | 0.2起步，每次加0.1，强磁电机Ki太大会猛转打滑 |
| Kd适当加大 | 强磁电机需要更多阻尼抑制猛响应 |
| 减速要平滑 | 强磁电机扭矩大，突然减速容易打滑 |
| 分段PID | 弯道用不同的参数（kp大+kd大+gkd小） |
| 地推阻力大是正常的 | 强磁电机低速扭矩大，阻力比普通电机大很多 |

## 六、调参顺序快速参考

```
第0步：地推测试 → 确认Kp范围（你的：40~43）
第1步：速度环只开P(Kp=40) → 车能跑
第2步：速度环加I(Ki=0.2起) → 车速精确
第3步：速度环加D(Kd=0.5起) → 加减速平滑
第4步：提速测试（80→150）
第5步：转向环只开P(kp=25) → 车能走直线
第6步：转向环加kp2(1.0) → 急弯更有力
第7步：转向环加kd(2.0) → 转弯回正平滑
第8步：转向环加gkd(35) → 高速更稳
第9步：联合测试
第10步：直角弯测试
第11步：加转向ki
第12步：分段PID
```

**每次只改一个参数！改完跑一圈记录效果再改下一个。**
