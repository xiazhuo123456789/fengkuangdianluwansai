# 增量式PI速度环问题分析与解决方案

## 一、问题背景

智能车三串级PID控制中，内环（速度环）使用增量式PI控制器。在实际调试中发现：

> **未发车静止时，左右轮输出最大PWM；按下发车开关瞬间，小车直接满速冲出去。**

---

## 二、增量式PI原理

### 公式

```
Δu = Kp × (e_k - e_{k-1}) + Ki × e_k
output = last_output + Δu
```

其中：
- `e_k` = 当前误差 = 目标速度 - 实际速度
- `e_{k-1}` = 上一次误差
- `last_output` = 上一次输出

### 与位置式PI的对比

| 特性 | 位置式PI | 增量式PI |
|------|---------|---------|
| 输出 | 绝对值 | 增量累加 |
| 公式 | `u = Kp×e + Ki×Σe` | `Δu = Kp×(e_k - e_{k-1}) + Ki×e_k` |
| 积分饱和 | 需要积分限幅 | 天然无饱和问题 |
| 切换扰动 | 有跳变 | 无跳变（增量累加） |
| 内存需求 | 需要存储积分累加 | 需要存储last_output和last_error |

## 三、问题根因分析

### 3.1 静止时的误差累积

```
静止状态（run_flag=0）：
  目标速度 target = 1200（base_speed）
  实际速度 actual = 0（车没动）
  误差 error = 1200 - 0 = 1200（极大）

  每个控制周期（3ms）都在执行：
  increment = Kp × (1200 - 0) + Ki × 1200
  last_output += increment
  → last_output 不断增大
```

### 3.2 发车时的冲击

```
发车瞬间（run_flag从0变1）：
  last_output 已经累积到很大值
  电机立即收到 last_output（大值）
  → 左右轮满速输出
  → 小车猛冲出去
```

### 3.3 时序图

```
时间轴：
  |---静止期---|---发车---|---运行---|
  |  run=0     |  run=1   |  run=1   |
  |            |          |          |
  | PI在计算   | PI输出   | PI正常   |
  | 但没输出   | → 满速！ | → 正常   |
  | (被挡住了) | (突然释放)|          |
```

## 四、解决方案对比

### 方案A：发车瞬间清零PI状态

```c
if (run_flag == 1 && last_run_flag == 0)
{
    inner_left.last_output = 0;
    inner_right.last_output = 0;
    inner_left.error = 0;
    inner_right.error = 0;
}
```

**优点**：简单直接
**缺点**：可能有1帧跳变（清零和输出之间有时间差）

### 方案B：发车使能标志位锁死速度环（推荐）

```c
// 静止时：不进速度环，直接输出0
if (run_flag == 0)
{
    motor_proc(0, 0);
    return;  // PI不执行，状态不更新
}

// 发车时：才开始速度环计算
// output从0开始，无累积
l_pwm = pid_incremental(&inner_left, l_target, l_now_vel);
```

**优点**：从根源杜绝累积，完全无跳变
**缺点**：需要在代码结构上保证PI计算被跳过

### 方案对比

| 方案 | 原理 | 效果 | 推荐度 |
|------|------|------|--------|
| A：发车清零 | 发车瞬间重置PI内部状态 | 可能有1帧跳变 | ⭐⭐⭐ |
| B：使能锁死 | 静止时不执行PI计算 | 完全无累积，零跳变 | ⭐⭐⭐⭐⭐ |

## 五、推荐方案详解（方案B）

### 5.1 控制流程

```
control_proc() {
    if (run_flag == 0) {
        motor_proc(0, 0);   // 直接输出0
        return;              // PI不执行
    }

    // 内环3ms：增量式PI
    if (++inner_cnt >= 3) {
        l_pwm = pid_incremental(...);
        r_pwm = pid_incremental(...);
        motor_proc(l_pwm, r_pwm);
    }

    // 中环6ms...
    // 外环12ms...
}
```

### 5.2 关键点

1. **`return` 必须在 PI 计算之前**——确保静止时 PI 完全不执行
2. **`last_output` 初始值为 0**——发车后第一个周期输出从 0 开始
3. **不需要额外清零逻辑**——因为 PI 从未执行过，状态自然是初始值

### 5.3 安全检查清单

- [ ] `run_flag == 0` 时，PI 计算被完全跳过
- [ ] `last_output` 初始值为 0
- [ ] `error` 和 `last_error` 初始值为 0
- [ ] 发车后第一个周期的输出是小值而非大值
- [ ] 电机 PWM 在发车瞬间无突变

## 六、其他注意事项

### 6.1 编码器数据有效性

静止时编码器读数为0，但 `l_now_vel` 和 `r_now_vel` 可能有噪声。建议在速度环中加低通滤波：

```c
l_now_vel = l_now_vel * 0.7f + new_vel * 0.3f;
```

### 6.2 增量式PI的积分饱和问题

增量式PI天然无积分饱和问题（因为输出是增量累加，不是积分累加），但如果 `last_output` 被限幅截断，增量会丢失。建议：

```c
// 先不限幅，让增量累积
float output = pid->last_output + increment;
// 最后再限幅输出到电机
output = limit_float(output, MAX, -MIN);
// 但 last_output 保存未限幅的值（保留增量信息）
pid->last_output = output;
```

### 6.3 位置式vs增量式选择建议

| 环 | 推荐 | 原因 |
|----|------|------|
| 外环（图像） | 位置式 | 需要绝对输出，图像偏差直接对应转向量 |
| 中环（角速度） | 位置式 | 角速度误差直接对应速度差 |
| 内环（速度） | 增量式 | 切换无扰动，天然无积分饱和 |

---

## 七、总结

| 项目 | 内容 |
|------|------|
| 问题 | 增量式PI在静止时累积误差，发车瞬间满速冲击 |
| 根因 | PI在`run_flag=0`时仍执行计算，`last_output`持续累加 |
| 最佳方案 | 发车使能标志位锁死速度环，静止时不执行PI |
| 核心代码 | `if (run_flag == 0) { motor_proc(0,0); return; }` |
| 额外注意 | 编码器噪声滤波、增量式限幅策略、三环各自的PI类型选择 |
