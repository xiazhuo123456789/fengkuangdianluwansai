# 直角弯完整攻略：内切圆 + 转弯时机 + 代码修改

---

## 一、核心问题：你现在是怎么转直角弯的

```
你现在的代码（node_proc NODE_TURNING）：
  1. find_guaidian() → 发现拐点
  2. find_rect_path() → 画矩形框验证
  3. bias_left() / bias_right() → 中线强制拉到左/右边缘
  4. 等 yaw 转够目标角度（±20度容差）→ 退出

问题：
  bias_left/right 是"一刀切"——把整条中线拉到图像最边缘
  没有"内切圆"的概念，没有"外-内-外"的平滑路径
  → 要么转太急（冲出去），要么转不够（回不来）
```

## 二、正确的直角弯应该怎么做

### 赛车线原理（外-内-外）

```
俯视图：

          ┃
          ┃ ← 赛道
          ┃
    ──────╋──────→
         ╱
        ╱  ← 正确的转弯路径（外→内→外）
       ╱
      ╱

放大看转弯区域：

     ╔══════╗
     ║  内侧 ║  ← 车应该贴近这里
     ║      ║
     ║      ║
     ╚══════╝
     ↑ 入弯点        ↑ 出弯点
     从外侧入        到外侧出
```

```
错误做法（你现在的）：
  车在赛道中间 → 直接拉中线到边缘 → 猛转 → 冲出去

正确做法（外-内-外）：
  阶段1（入弯前）：车在赛道中间偏外侧
  阶段2（弯中）：  车贴近弯道内侧（内切圆）
  阶段3（出弯后）：车回到赛道中间偏外侧
```

### 三段式速度控制

```
距离 →
|← 直道全速 →|← 减速入弯 →|← 弯中低速 →|← 加速出弯 →|← 直道全速 →|
     150           100            75            100           150
```

| 阶段 | 速度 | 转向 | 你的代码里有吗 |
|------|------|------|:---:|
| 入弯前减速 | 降到50% | 正常循迹 | ✅ 刚加了 |
| 弯中保持低速 | 保持50% | bias_left/right | ✅ 有 |
| 出弯加速 | 恢复全速 | 检测到新赛道线 | ❌ 没有（直接退出） |

## 三、关键问题：什么时候开始转

### 网友经验总结

```
核心原则："宁早勿晚"
  入弯稍早 → 可以修正（调整内切点）
  入弯稍晚 → 无法挽回（冲出去了）

入弯时机 = 前轮到达弯道入口前 0.5~1 个车身长度
```

### 你的代码里的入弯时机

```
你的代码：
  find_guaidian(ROW-5, 40) → 检测行40~115
  → 发现拐点 → 立即进入 NODE_TURNING → 立即 bias_left/right

问题：拐点在行40检测到时，车实际距离弯道还有多远？
  行40 对应摄像头图像的中上方区域
  如果摄像头安装高度30cm，行40大约对应车前方 30~50cm
  → 拐点发现时车已经很近了 → 来不及做内切
```

### 改进建议：降低检测行号

```
现在：find_guaidian(ROW-5, 40) → 只看到行40~115
改为：find_guaidian(ROW-5, 20) → 看到行20~115（多看20行远处）

行20 对应更远的距离 → 更早发现弯道 → 有时间做内切
```

## 四、具体代码修改方案

### 修改1：扩大拐点检测范围（更早发现弯道）

```c
// image.c NODE_NONE 中，原来：
find_guaidian(ROW - 5, 40);     // 只看到行40

// 改为：
find_guaidian(ROW - 5, 20);     // 看到行20（更远）
```

### 修改2：三段式转向（入弯→弯中→出弯）

你现在是"一刀切"（全程 bias_left/right）。改成三段：

```
NODE_TURNING 分三个阶段：

阶段1（入弯）：刚检测到弯道，中线从正常位置慢慢偏移
  → 不是直接拉到边缘，而是逐步偏移
  → 让车平滑地从赛道中间过渡到弯道内侧

阶段2（弯中）：车在弯道内侧
  → bias_left/right 全力偏置
  → 保持低速

阶段3（出弯）：检测到新赛道线出现
  → 逐步恢复中线到正常位置
  → 加速恢复
```

### 修改3：出弯检测（比现在更精确）

```
现在的退出条件：yaw 转够目标角度 ± 20度
  → 20度太宽松，可能转70度就退出了

改进的退出条件（三重验证）：
  1. yaw 转够目标角度（±10度，更精确）
  2. 重新检测到赛道线（不是空白）
  3. 赛道线方向和预期一致（确认已经到了新赛道）
```

### 修改4：分段PID参数

```
直道PID：Kp=25, Kd=2.0  （你现在用的）
弯道PID：Kp=40, Kd=5.0  （更大响应+更大阻尼）

在 NODE_TURNING 时切换到弯道PID参数
```

## 六、内切圆在图像中的体现

```
直角右弯，摄像头看到的画面：

正常直道时：
  行:  l_border  r_border  中线
  80:   65       115       90     ← 中线在中间
  60:   70       110       90
  40:   75       105       90
  20:   80       100       90     ← 远处也居中

入弯时（bias_right 生效）：
  行:  l_border  r_border  中线
  80:   65       115       90     ← 近处还没变
  60:   70       110       90
  40:   75       150       112    ← 中线开始右偏（内切开始）
  20:   80       180       130    ← 远处中线偏右（弯道方向）

弯中时：
  行:  l_border  r_border  中线
  80:   65       115       90     ← 近处还在弯道入口
  60:   70       110       90
  40:   80       170       125    ← 中线大幅右偏（贴近内侧）
  20:   85       180       132    ← 远处已经看到新赛道

出弯时（新赛道线出现）：
  行:  l_border  r_border  中线
  80:   60       120       90     ← 近处也开始恢复
  60:   65       115       90
  40:   70       110       90     ← 中线回到中间
  20:   75       105       90     ← 远处已经完全恢复
```

**"内切圆"在图像中的样子：中线从中间→偏右→回中间，形成一个平滑的弧线，而不是突然跳变。**

## 七、调参步骤（实操）

```
第1步：先确认减速生效
  跑一圈，看 IPS114 屏幕上的速度值
  到直角弯时速度应该从150降到75
  如果没降 → 检查控制代码

第2步：调容差
  把20度改成10度，跑一圈
  如果转不够就退出 → 容差太小，改回15度
  如果转太多才退出 → 容差太大，改小

第3步：扩大检测范围
  把40改成20，跑一圈
  如果提前发现弯道且减速了 → 好
  如果误判增多 → 改成25或30

第4步：调PID参数
  在控制.c中定义弯道PID：
  直道：Kp=25, Kd=2.0
  弯道：Kp=40, Kd=5.0
  根据实际效果微调
```
