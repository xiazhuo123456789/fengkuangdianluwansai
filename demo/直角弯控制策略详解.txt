一、问题背景
============================================================

智能车在直角弯处常见的问题：

1. 速度太快，惯性太大，车冲出赛道（转向不足）
2. 轮子打滑，车身侧滑，偏离赛道（转向过度）
3. 摄像头视野有限，转弯过程中丢失赛道线
4. 纯靠图像偏差控制，响应不够快

根本原因：纯图像控制是"开环"的——只知道自己该往哪转，
不知道自己实际转了多少度。打滑时图像说"往左转"，
但车实际没转够，图像又说"继续往左"，形成死循环。


二、陀螺仪在直角弯中的作用
============================================================

陀螺仪检测的是车身实际旋转的角速度，不是轮子转了多少。

关键区别：
  轮子打滑 → 轮子转了但车身没转 → 编码器说转了，陀螺仪说没转
  车身侧滑 → 车身在转但不是正常转弯 → 陀螺仪能感知异常

所以陀螺仪能回答一个图像回答不了的问题：
  "车到底转了多少度？"

三种传感器的分工：
  摄像头 → 知道赛道在哪（位置信息）
  陀螺仪 → 知道车转了多少（姿态信息）
  编码器 → 知道车走了多远（距离信息）


三、控制策略对比
============================================================

策略1：纯图像控制（当前方案）
------------------------------------------------------------
  原理：图像偏差 → PID → 转向PWM
  优点：简单、好调参
  缺点：不知道实际转了多少，打滑时失控

  控制流程：
    图像偏差 → kp*error → 转向输出

策略2：陀螺仪角度闭环（推荐升级）
------------------------------------------------------------
  原理：目标角度 - 实际角度 → PID → 转向PWM
  优点：知道实际转了多少，打滑时能补偿
  缺点：不知道赛道在哪，需要和图像配合

  控制流程：
    目标角度(90°) - yaw_total → PID → 转向输出

策略3：摄像头+陀螺仪融合（最佳方案）
------------------------------------------------------------
  原理：图像给方向，陀螺仪给精度，两者互补
  优点：既有位置信息又有姿态信息，抗打滑
  缺点：需要设计融合策略

  控制流程：
    图像偏差 → 图像PID ─┐
                         ├→ 融合 → 转向输出
    陀螺仪角度 → 角度PID ─┘


四、直角弯分段控制（最实用的方案）
============================================================

将直角弯分成三个阶段，每个阶段用不同的控制策略：

  入弯阶段 → 减速 + 检测到弯道
  弯道中   → 陀螺仪角度闭环 + 低速
  出弯阶段 → 恢复速度 + 切回图像循迹

┌─────────────────────────────────────────┐
│  入弯                                     │
│  1. 检测到直角弯（拐点+路径数==2）          │
│  2. 立即减速（降低base_speed）              │
│  3. 记录当前yaw_before_turn               │
│  4. 切换到角度闭环模式                      │
├─────────────────────────────────────────┤
│  弯道中                                   │
│  1. 目标角度 = yaw_before_turn ± 90°      │
│  2. 用PID控制转向，让实际角度逼近目标角度     │
│  3. 保持低速，防止打滑                      │
│  4. 持续检测图像，确认赛道线重新出现          │
├─────────────────────────────────────────┤
│  出弯                                     │
│  1. 实际角度到达目标附近（±15°）             │
│  2. 恢复速度                               │
│  3. 切回图像循迹模式                        │
│  4. 清除状态，等待下一个路口                 │
└─────────────────────────────────────────┘


五、速度分段控制
============================================================

不同阶段用不同速度，防止打滑和冲出赛道：

  直道：全速（base_speed = 1200）
    ↓ 检测到弯道
  入弯前：减速（base_speed = 600~800）
    ↓ 进入弯道
  弯道中：低速（base_speed = 400~600）
    ↓ 转够角度
  出弯后：逐渐加速（600 → 800 → 1200）

速度建议：
  直道速度：1000~1200（根据赛道条件）
  弯道速度：400~600（防止打滑的关键）
  加速梯度：每帧加50~100（不能突然加速）


六、打滑检测与补偿
============================================================

打滑检测方法：
  编码器速度 ≠ 陀螺仪角速度 → 可能在打滑

  正常转弯：轮子转速 ≈ 车身角速度 × 转弯半径
  打滑时：  轮子转速 >> 车身角速度（轮子空转）
  侧滑时：  轮子转速 << 车身角速度（车在滑）

打滑补偿：
  检测到打滑 → 降低速度 → 等待恢复 → 重新控制

  if (encoder_speed > gyro_speed * threshold)
  {
      // 轮子空转，减速
      base_speed *= 0.8f;
  }


七、陀螺仪角度闭环PID
============================================================

角度闭环的PID控制：

  error = 目标角度 - 当前yaw_total
  turn_pwm = angle_kp * error + angle_kd * d_error

参数建议：
  angle_kp：20~40（太大震荡，太小转不过来）
  angle_kd：1~3（抑制超调）

注意：
  - 角度PID和图像PID是两套独立的PID
  - 弯道中用角度PID，直道中用图像PID
  - 切换时要平滑过渡，不能突然跳变


八、代码实现思路
============================================================

在现有代码基础上修改 node_proc()：

1. NODE_NONE 状态：
   - 检测到直角弯 → 记录yaw_before_turn → 减速
   - 切换到 NODE_TURNING

2. NODE_TURNING 状态（直角弯）：
   - 计算目标角度 = yaw_before_turn ± 90°
   - 用角度PID控制转向
   - 弯道中保持低速
   - 角度到位 + 图像检测到赛道线 → 退出

3. 退出条件改进：
   - 当前：只看角度（±20°余量）
   - 改进：角度到位（±15°） AND 图像重新检测到赛道线
   - 双重确认，防止误判

伪代码：
  case NODE_TURNING:
      if (turn_dir == TURN_LEFT)
      {
          // 保持低速
          actual_speed = 500;

          // 角度闭环
          float target = yaw_before_turn - 90.0f;
          float error = target - yaw_total;
          steer = angle_kp * error;

          // 退出条件：角度到位 + 图像有赛道线
          if (fabsf(error) < 15.0f
              && (l_border[ROW-5] > 5 || r_border[ROW-5] < COL-5))
          {
              // 转向完成，恢复速度
              actual_speed = base_speed;
              node_reset_state();
          }
      }


九、调参建议
============================================================

分步调参（照着做）：

第1步：先调图像PID（不加陀螺仪）
  - 直道稳不稳
  - 弯道能转过去吗
  - kp从30开始加

第2步：加陀螺仪前馈（gkd）
  - 弯道处抗干扰更好
  - gkd从20开始加

第3步：调弯道减速
  - 入弯前减速到多少
  - 弯道中保持多少速度
  - 出弯后怎么恢复

第4步：调角度闭环参数
  - angle_kp从20开始
  - 角度到位的容差从25°开始缩小

第5步：调退出条件
  - 角度容差：25° → 20° → 15°
  - 图像确认条件：赛道线宽度阈值


十、总结
============================================================

核心思路：
  直道：以图像为主（循线）
  弯道：以陀螺仪为主（角度控制）
  过渡：平滑切换（不能突变）

你现在需要做的改动（按优先级）：
  1. 弯道减速（最简单，效果最明显）
  2. 退出条件加图像确认（防误判）
  3. 角度闭环PID（精度提升）
  4. 打滑检测（锦上添花）

不需要一步到位，先把弯道减速做好，效果就会明显提升。
