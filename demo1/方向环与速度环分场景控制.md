# 方向环调硬保证转向响应，速度环分场景控制（直道硬、入弯主动降速）

## 实现步骤：直道硬速度环 + 入弯主动降速

核心逻辑：先用传感器识别前方直角弯，主动降低速度环的目标转速，同时可切换速度环PI参数（直道硬、弯道软）。**核心是降目标速度，参数切换只是辅助优化。**

---

## 一、第一步：识别直角弯（触发降速的开关）

### 1. 摄像头方案（推荐，前瞻远、提前量足）

三种常用方法，从简单到精准：

#### 方法1：远前瞻偏差阈值法（新手首选）

- 取图像中较远的一行（比如第20行，离车身30~50cm），计算这一行黑线的中心偏差。
- 直道时偏差接近0；当远前瞻偏差连续几次超过阈值，判定前方有急弯/直角，触发降速。
- **优点**：代码几行就能写好
- **缺点**：缓弯和直角区分度一般，需调阈值防抖

#### 方法2：拐点检测法（精准对应直角弯）

- 逐行扫描黑线，检测路径方向突变的拐点。当出现90°左右的拐点，且距离车身在预设范围内，判定为直角弯，触发降速。
- **优点**：只针对直角弯触发，不误判
- **缺点**：需要写简单的拐点识别逻辑

#### 方法3：弯道半径法（适配所有弯道）

- 取近、中、远三个前瞻点，用三点法拟合弯道半径。半径小于阈值时，判定为急弯，半径越小，降速越多。
- **优点**：能按弯道急缓自动调速
- **缺点**：计算量稍大

### 2. 八路灰度方案

- 灰度传感器前瞻近，只能就近触发：当最外侧的传感器踩到黑线，说明弯道很急，立刻触发降速。
- **缺点**：提前量小，减速必须猛，容易打滑。建议额外加一排前瞻灰度，或斜向安装传感器，增加提前距离。

---

## 二、第二步：三段式主动降速逻辑

识别到弯道后，目标速度不能瞬间跳变，要分三个阶段平滑过渡：

### 1. 预减速阶段（入弯前）

- 远前瞻检测到直角，立刻开始线性降速，保证入弯前车速降到安全值。
- **关键**：提前量要够。前瞻越远，减速可以越平缓，车身越稳。

### 2. 弯中稳速阶段

- 进入弯道后，目标速度维持定值。
- 参考值：直角弯弯中速度 = 直道速度 × 50%~70%，轮胎抓地力差就再降。

### 3. 出弯提速阶段

- 检测到弯道结束（偏差回到直道水平、拐点消失），逐步把速度拉回直道高速，不要一下拉满，防止打滑、车身抖。

> ⚠️ **必加约束**：目标速度加斜率限制。每次循环只加/减固定数值，避免速度跳变导致轮子打滑、电机震荡。

---

## 三、进阶：同步切换速度环软硬（PI动态切换）

配合目标速度，同时切换速度环的PI参数，既保直道高速，又防过弯过冲：

| 场景 | PI参数 | 效果 |
|------|--------|------|
| 直道 | 硬PI（大P大I） | 提速快、稳速准，满足高速需求 |
| 弯道 | 软PI（小P小I） | 过弯阻力变化时，电机不会猛补扭矩，避免"一边打方向一边踩油门"，减少过冲 |

> ⚠️ 切换参数时，**清空速度环的积分累计值**，防止积分饱和，导致切换瞬间输出突变、车身顿挫。

## 四、极简代码框架（C语言，直接套用）

```c
// 全局变量
float target_speed;       // 速度环目标速度
float speed_kp, speed_ki; // 速度环PI参数
float speed_integral;     // 速度环积分项
uint8_t is_right_angle = 0; // 直角弯标志位

// 1. 直角弯识别（放在图像/灰度采集后执行）
void corner_detect(void)
{
    // 示例：远前瞻偏差超过80，且连续3次满足，判定为直角
    static uint8_t cnt = 0;
    if( far_line_deviation > 80 )
    {
        cnt++;
        if(cnt >= 3)  is_right_angle = 1;
    }
    else
    {
        cnt = 0;
        is_right_angle = 0;
    }
}

// 2. 动态速度+PI控制（放在速度环计算前执行）
void speed_plan(void)
{
    // 动态目标速度（带斜坡，防止跳变）
    if(is_right_angle == 1)
    {
        // 直角弯：逐步降到300（单位对应你的转速/速度值）
        if(target_speed > 300)
            target_speed -= 5; // 减速斜率，数值越大降得越快
    }
    else
    {
        // 直道：逐步升到600（直道高速）
        if(target_speed < 600)
            target_speed += 3; // 加速斜率
    }

    // 动态切换PI参数
    if(is_right_angle == 1)
    {
        speed_kp = 15;  // 弯道软PI
        speed_ki = 0.3;
        speed_integral = 0; // 切换时清积分，防饱和
    }
    else
    {
        speed_kp = 30;  // 直道硬PI
        speed_ki = 0.6;
    }

    // 之后执行速度环PID计算，输出PWM
}
```

## 五、调试顺序（按步骤来，不翻车）

| 步骤 | 内容 | 要点 |
|------|------|------|
| 1 | **先调识别** | 低速跑车，确认直角弯能准确触发，直道不误判。加防抖计数，避免干扰误触发。 |
| 2 | **再调降速幅度** | 先把弯中速度设低（比如直道的一半），保证不冲弯，再慢慢往上提速。 |
| 3 | **调加减速斜率** | 减速太猛就减小每次降的数值，太缓就加大，做到入弯前刚好降到目标速度。 |
| 4 | **最后调PI切换** | 先调好直道硬PI、弯道软PI两套参数，再做切换，微调直到切换无顿挫、无抖动。 |

---

## 关键提醒

1. **解决直角冲弯，降目标速度是核心，PI切换只是优化。** 就算速度环再软，目标速度很高，高速入弯照样冲。
2. **直角弯的提前量比降速幅度更重要。** 一定要在入弯前把速度降下来，进了弯再降就晚了。
3. **不要追求一步到位**，先低速验证逻辑，再逐步拉高直道速度。
