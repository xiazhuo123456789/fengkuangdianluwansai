# 智能车12路口运行流程分析

## 项目概述

- **硬件平台**: Infineon TC264 (Aurix Tricore)
- **传感器**: MT9V03X摄像头 + IMU660RB陀螺仪 + 编码器
- **执行器**: 左右直流电机(PWM驱动) + 蜂鸣器
- **算法**: 摄像头二值化循迹 + OTSU自适应阈值 + 陀螺仪辅助PID转向

## 路径规划

共12个路口,路径定义在 `code/image.c` 的 `path[]` 数组中:

```
路口 1:  TURN_RIGHT   (右转)
路口 2:  TURN_LEFT    (左转)
路口 3:  TURN_RIGHT   (右转)
路口 4:  TURN_RIGHT   (右转)
路口 5:  TURN_RIGHT   (右转)
路口 6:  TURN_LEFT    (左转)
路口 7:  TURN_LEFT    (左转)
路口 8:  TURN_LEFT    (左转)
路口 9:  GO_STRAIGHT  (直行)
路口 10: TURN_RIGHT   (右转)
路口 11: GO_STRAIGHT  (直行)
路口 12: GO_STRAIGHT  (直行)
```
