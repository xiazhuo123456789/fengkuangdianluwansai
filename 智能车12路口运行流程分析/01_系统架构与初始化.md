# 系统架构与初始化

## 一、定时器中断架构

系统使用3个定时器中断驱动所有实时任务:

| 定时器 | 周期 | 中断函数 | 调用的业务函数 |
|--------|------|----------|----------------|
| CCU60_CH1 | 1ms | cc60_pit_ch1_isr | control_proc(), 每10ms调用key_proc() |
| CCU61_CH0 | 5ms | cc61_pit_ch0_isr | gyro_proc(), encoder_proc() |
| CCU61_CH1 | 10ms | cc61_pit_ch1_isr | run_time_proc() |

中断服务程序位于 `user/isr.c`。

### 1ms中断详细逻辑 (isr.c:4-18)

```
cc60_pit_ch1_isr:
    清除中断标志 pit_clear_flag(CCU60_CH1)
    static uint8 timer_10ms
    if(++timer_10ms >= 10):        // 每10ms执行一次
        timer_10ms = 0
        key_proc()                 // 按键扫描
    control_proc()                 // 每1ms都执行控制输出
```

### 5ms中断详细逻辑 (isr.c:20-27)

```
cc61_pit_ch0_isr:
    清除中断标志 pit_clear_flag(CCU61_CH0)
    gyro_proc()                    // 陀螺仪数据采集与偏航积分
    encoder_proc()                 // 编码器读取与里程累计
```

### 10ms中断详细逻辑 (isr.c:29-35)

```
cc61_pit_ch1_isr:
    清除中断标志 pit_clear_flag(CCU61_CH1)
    run_time_proc()                // 发车计时与超时停车
```

## 二、主循环 (cpu0_main.c)

```
core0_main():
    peripheral_init()              // 全部外设初始化
    while(TRUE):
        debug_proc()               // 无线调试通信
        image_proc()               // 图像采集与处理
        if(!start_flag):           // 待机时显示画面
            ips114_show_gray_image(bin_image)
            ips114_show_int(image_err)
            ips114_show_int(node_state)
```

## 四、初始化详细流程 (init.c)

`peripheral_init()` 按顺序执行以下初始化:

```
peripheral_init():
    (1)  clock_init()                  系统时钟配置
    (2)  debug_init()                  调试串口初始化
    (3)  无线模块初始化(条件编译):
         - WIRELESS_UART_ENABLE: wireless_uart_init()
         - BLE6A20_ENABLE:      ble6a20_init()
         - WIFI_SPI_ENABLE:     wifi_spi_init() + TCP连接
    (4)  mt9v03x_double_init(mt9v03x_1)     MT9V03X摄像头初始化(阻塞)
    (5)  seekfree_assistant_interface_init() 无线图传接口
    (6)  seekfree_assistant_camera_information_config(bin_image, 188, 120)
    (7)  seekfree_assistant_camera_boundary_config(l_border, mid_line, r_border)
    (8)  ips114_init()                 1.8寸LCD屏幕初始化
    (9)  encoder_dir_init(ENCODER_L)   左编码器(TIM4)
    (10) encoder_dir_init(ENCODER_R)   右编码器(TIM6)
    (11) pwm_init(MOTOR_PWM_L, 17000, 0)   左电机PWM 17kHz
    (12) pwm_init(MOTOR_PWM_R, 17000, 0)   右电机PWM 17kHz
    (13) gpio_init(MOTOR_DIR_L, GPO, HIGH) 左电机方向
    (14) gpio_init(MOTOR_DIR_R, GPO, HIGH) 右电机方向
    (15) pwm_init(FUYA_PWM, 17000, 0)      蜂鸣器PWM
    (16) gpio_init(KEY1~KEY4, GPI, HIGH, PULL_UP) 4个按键
    (17) gyro_init()                   陀螺仪初始化
         - imu660rb_init()             IMU硬件初始化
         - IMU_gyro_Offset_Init()      零偏校准(采样100次取平均)
         - gyro_Offset_flag = 1
    (18) pid_param_init()              PID参数
         - steer_pid.kp  = 20         图像误差比例系数
         - steer_pid.gkd = 30         陀螺仪微分系数
    (19) pit_ms_init(CCU60_CH1, 1)     1ms定时器中断
    (20) pit_ms_init(CCU61_CH0, 5)     5ms定时器中断
    (21) pit_ms_init(CCU61_CH1, 10)    10ms定时器中断
    (22) cpu_wait_event_ready()        等待所有核心就绪
```

## 五、初始化后全局变量状态

| 变量名 | 初始值 | 所在文件 | 含义 |
|--------|--------|----------|------|
| run_flag | 0 | swj.c | 运行标志 |
| start_flag | 0 | key.c | 启动标志 |
| node_count | 0 | image.c | 路口计数 |
| node_state | NODE_NONE(0) | image.c | 节点状态机状态 |
| turn_dir | TURN_NONE(0) | image.c | 当前转向方向 |
| std_yaw | 0.0f | image.c | 标准偏航角(目标) |
| yaw_total | 0.0f | gyroscope.c | 累计偏航角 |
| total_dist | 0.0f | encoder.c | 累计行驶距离(m) |
| image_err | 0.0f | image.c | 图像中线偏差 |
| steer_pwm_out | 0.0f | control.c | 转向PWM输出 |
| l_speed_output | 0.0f | control.c | 左轮速度输出 |
