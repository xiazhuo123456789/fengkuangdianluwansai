# 待机与发车流程

## 一、待机阶段

初始化完成后进入待机状态,`run_flag=0`, `start_flag=0`。

### 1.1 主循环运行

```
image_proc() 每帧执行:
    if(mt9v03x_finish_flag_1):           // 摄像头一帧采集完成
        mt9v03x_finish_flag_1 = 0        // 清除标志
        image_binarize(mt9v03x_image_1)  // 二值化处理
        search_line()                    // 扫描边线
        node_proc(bin_image)             // 节点检测(待机时无实际动作)
        calc_image_error()               // 计算中线偏差

屏幕显示:
    ips114_show_gray_image(bin_image)    // 显示二值化图像
    ips114_show_int(image_err)           // 显示图像误差
    ips114_show_int(node_state)          // 显示节点状态
```

### 1.2 中断运行但无效果

```
1ms中断 → control_proc():
    run_flag == 0:
        motor_proc(0, 0)     // 两轮输出0,车不动

5ms中断:
    gyro_proc()              // 陀螺仪持续采集,但车不动yaw不变
    encoder_proc()           // 编码器读取,但车不动值为0

10ms中断 → run_time_proc():
    start_flag == 0:         // 不计时,直接返回
```

## 二、按键发车

### 2.1 按键扫描逻辑 (key.c)

每10ms执行一次 `key_proc()`:

```
key_proc():
    key_val = key_read()                 // 读取按键状态
    key_down = key_val & (key_val ^ key_old)  // 检测下降沿(按下瞬间)
    key_up  = ~key_val & (key_val ^ key_old)  // 检测上升沿(松开瞬间)
    key_old = key_val                    // 保存上次状态

    switch(key_down):
        case 1:  reset_all()    // KEY1按下 → 复位全部状态
        case 2:  reset_all()    // KEY2按下 → 复位全部状态
        case 3:  reset_all()    // KEY3按下 → 复位全部状态
        case 4:                 // KEY4按下 → 切换启动标志
            if(++start_flag >= 2):
                start_flag = 0  // 0→1→0→1... 循环切换
```

### 2.2 key_read() 读取引脚

```
key_read():
    temp = 0
    if(gpio_get_level(KEY1)==0) temp=1   // P20_6 低电平有效
    if(gpio_get_level(KEY2)==0) temp=2   // P20_7
    if(gpio_get_level(KEY3)==0) temp=3   // P11_2
    if(gpio_get_level(KEY4)==0) temp=4   // P11_3 → 发车按键
    return temp
```

## 三、发车倒计时

按下KEY4后 `start_flag=1`,10ms中断中的 `run_time_proc()` 开始计时。

### 3.1 run_time_proc() 详细逻辑 (control.c:75)

```
run_time_proc():
    static uint16 cnt_10ms = 0
    static uint16 timer_1s = 0

    if(start_flag):                      // start_flag=1,开始计时
        cnt_10ms++                       // 每10ms加1

        if(cnt_10ms >= 100):             // 满1秒
            cnt_10ms = 0
            timer_1s++

            timer_1s == 1:               // 第1秒
                fuya_flag = 1            // ★ 蜂鸣器开启(发车提示音)
                → set_fuya_pwm(FUYA_PWM_DUTY)
                → FUYA_PWM_DUTY = (40 * PWM_DUTY_MAX) / 100 = 40%占空比

            timer_1s == 2:               // 第2秒
                run_flag = 1             // ★★★ 车辆开始运行!

            timer_1s == RUN_TIME(15):    // 第15秒
                run_flag = 0             // ★ 停止运行

            timer_1s == 16:              // 第16秒
                fuya_flag = 0            // 关闭蜂鸣器
                start_flag = 0           // 重置启动标志
                timer_1s = 0             // 重置计时器
                cnt_10ms = 0             // 重置10ms计数
```

### 3.2 时间线总结

| 时刻 | 事件 | 关键变量变化 |
|------|------|--------------|
| 0s | 按下KEY4 | start_flag: 0→1 |
| 0~1s | 等待 | cnt_10ms累加 |
| 1s | 蜂鸣器响 | fuya_flag: 0→1 |
| 2s | 车辆启动 | run_flag: 0→1 |
| 2s~15s | 正常行驶 | 所有模块联动 |
| 15s | 停止运行 | run_flag: 1→0 |
| 16s | 完全停止 | fuya_flag→0, start_flag→0 |

### 3.3 蜂鸣器控制 (control.c:63)

```
fuya_proc():                             // 主循环中调用(当前被注释)
    if(fuya_flag):
        set_fuya_pwm(FUYA_PWM_DUTY)     // 输出40%占空比PWM
    else:
        set_fuya_pwm(0)                 // 关闭PWM
```

`set_fuya_pwm()` (motor.c:50):
```
set_fuya_pwm(int fuya):
    if(fuya >= 0):
        pwm_set_duty(FUYA_PWM, fuya)
    else:
        pwm_set_duty(FUYA_PWM, -fuya)
```
