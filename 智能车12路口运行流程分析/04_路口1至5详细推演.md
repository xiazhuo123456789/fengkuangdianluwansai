# 路口1至5详细推演

## 路口状态机

所有路口共用同一个三状态状态机:

```
NODE_NONE ──(检测到拐点+路径>=3)──→ NODE_DETECTED ──(锁定yaw)──→ NODE_TURNING
    ↑                                                                    │
    └──────────────────(转向完成)─────────────────────────────────────────┘
```

---

## 路口1: TURN_RIGHT (右转)

### 第1步: 检测阶段 (NODE_NONE)

主循环每帧调用 `node_proc()`,当前 `node_state == NODE_NONE`:

```
node_proc() → case NODE_NONE:
│
├── find_guaidian(ROW-5=115, 40):
│   │   // 从row=115向上扫描到row=40,检测边线突变
│   │   // 进入路口时赛道分叉,右边线出现突变
│   │
│   └── for i = 115 down to 40:
│       ├── 检测左拐点:
│       │   if(l_guaidian==0 && abs(l_border[i]-l_border[i-5])>=50):
│       │       l_guaidian = i      // 左边线5行内跳变>=50像素
│       │
│       └── 检测右拐点:
│           if(r_guaidian==0 && abs(r_border[i]-r_border[i-5])>=50):
│               r_guaidian = i      // ★ 右边线突变,检测到右拐点
│
├── 假设结果: l_guaidian=0, r_guaidian=85
│
├── l_guaidian!=0 || r_guaidian!=0 → 检测到拐点
│
├── path_count = find_rect_path(bin_image):
│   │
│   ├── memset(&path_info, 0, sizeof)    // 清空路径信息
│   │
│   ├── 检测上边(row=RECT_TOP=20, col从RECT_LEFT=18到RECT_RIGHT-2=168):
│   │   for col = 18 to 168:
│   │       if(黑→白→白):  // bin_image[20][col]==BLACK && [col+1]==WHITE && [col+2]==WHITE
│   │           path_info.top_exist = 1
│   │           path_info.count++      // count=1
│   │           break
│   │   → T字路口上方有赛道
│   │
│   ├── 检测下边(row=RECT_BOTTOM=100, col从18到168):
│   │   → 检测到赛道: bottom_exist=1, count=2
│   │
│   ├── 检测左边(col=RECT_LEFT=18, row从RECT_TOP=20到RECT_BOTTOM-2=98):
│   │   → 假设未检测到: left_exist=0
│   │
│   └── 检测右边(col=RECT_RIGHT=170, row从20到98):
│       → 检测到赛道: right_exist=1, count=3
│
│   // 结果: path_count=3 (上+下+右), T字路口
│
├── path_count >= 3 → T字或十字路口:
│   │
│   ├── turn_dir = plan_turn():
│   │   │
│   │   ├── index = node_count % path_len = 0 % 12 = 0
│   │   │   // 注意: node_count此时还未自增
│   │   │
│   │   ├── planned = path[0] = TURN_RIGHT
│   │   │
│   │   ├── plan_warn_flag = 0           // 默认无警告
│   │   │
│   │   ├── 验证路径存在:
│   │   │   if(TURN_RIGHT && path_info.right_exist):  // right_exist=1 ✓
│   │   │       return TURN_RIGHT
│   │   │
│   │   └── return TURN_RIGHT
│   │
│   └── node_count++ → node_count = 1    // 路口计数+1
│
├── turn_dir = TURN_RIGHT, 不是TURN_NONE,继续
├── cur_paths = 3
└── node_state = NODE_DETECTED            // ★ 状态转移
```

### 第2步: 锁定偏航角 (NODE_DETECTED)

下一帧进入 `NODE_DETECTED`:

```
node_proc() → case NODE_DETECTED:
│
├── yaw_locked == 0 (首次进入) ✓
│
├── turn_dir == TURN_RIGHT:
│   ├── std_yaw += 90.0f                 // std_yaw: 0° → 90°
│   └── yaw_target = std_yaw = 90°       // 目标偏航角=90°
│
├── yaw_before_turn = yaw_total           // 记录转向前偏航 ≈ 0°
├── yaw_locked = 1                        // 锁定,后续帧不再重复
└── node_state = NODE_TURNING             // ★ 状态转移
```

### 第3步: 执行右转 (NODE_TURNING)

此后每一帧:

```
node_proc() → case NODE_TURNING:
│
├── find_guaidian(ROW-5=115, 30):
│   // 持续检测拐点,用于确定偏置起点
│   // 右转过程中r_guaidian逐渐下移
│
└── turn_dir == TURN_RIGHT → bias_right(bin_image):
    │
    ├── guaidian_row = r_guaidian          // 例如=80
    │
    ├── if(guaidian_row != 0) ✓:
    │   └── change_line(COL-1=187, guaidian_row=80, 187, 0):
    │       │
    │       ├── 参数限幅: x1=187,y1=80,x2=187,y2=0
    │       ├── a1=80, a2=0, 交换后 a1=0, a2=80
    │       │
    │       └── for i = 0 to 80:
    │           ├── hx = (i-80)*(187-187)/(0-80) + 187 = 187
    │           ├── if(hx>=188) hx=187; if(hx<=0) hx=0   // 限幅
    │           ├── mid_line[i] = 187      // ★ 中线=最右侧
    │           ├── l_border[i] = 187      // 左边线=最右侧
    │           └── r_border[i] = 187      // 右边线=最右侧
    │
    └── 效果: row 0~80的中线全部偏移到最右侧col=187
```

### 第4步: 右转时的控制链

```
// 主循环 calc_image_error():
// 远端(row 0~80) mid_line=187, 权重高(8)
// 近端(row 80~119) mid_line≈94, 权重低(1)
err_sum = Σ(187-94)*8 + Σ(94-94)*1 ≈ 大正值
image_err ≈ +45 (假设值)

// 1ms中断 control_proc() 每2ms:
steer_pwm_out = steer_pid_calc(+45, gyro_z, &steer_pid)
    = (+45 * 20) - (gyro_z * 30 / 100)
    = 900 - 小量
    ≈ +900
steer_pwm_out = limit(+900, 6000, -6000) = +900

// 1ms中断 control_proc() 每5ms:
l_speed_output = 1200 + 900 = 2100       // 左轮(外侧)加速
r_speed_output = 1200 - 900 = 300        // 右轮(内侧)减速
if(300 < 300)? 否,刚好=300

motor_proc(2100, 300):
    左轮: DIR=HIGH, PWM=2100 → 快速前进
    右轮: DIR=HIGH, PWM=300  → 慢速前进
    → ★ 差速产生右转弯力矩

// 5ms中断 gyro_proc():
// 车辆右转,gyro_z > 0
yaw_total 持续增大: 0° → 10° → 20° → ... → 60° → 70°
```

### 第5步: 右转完成判定

```
node_proc() → NODE_TURNING → TURN_RIGHT:
│
├── if(yaw_total >= yaw_target - 20.0f):
│   └── if(yaw_total >= 90 - 20 = 70°):
│       └── yaw_total达到70° ✓
│
├── yaw_after_turn = yaw_total            // ≈ 70°
├── delta_yaw = 70° - 0° = 70°
│
├── if(delta_yaw > 30.0f) ✓:
│   └── actual_turn_dir = TURN_RIGHT      // 实际转向=右转
│
├── if(actual_turn_dir == turn_dir):       // RIGHT == RIGHT ✓
│   └── turn_verify_flag = 1              // ★ 校验通过
│
└── node_reset_state(&yaw_locked, &cur_paths):
    ├── node_state = NODE_NONE             // 回到初始状态
    ├── turn_dir = TURN_NONE
    ├── yaw_locked = 0
    └── cur_paths = 0
```

### 第6步: 无线上报

```
wireless_uart_proc():
│
├── node_count从0变1:
│   sprintf → "总节点:12 | 当前:1 | 规划:右转\r\n"
│   wireless_uart_send_string(...)
│
└── turn_verify_flag从0变1:
    sprintf → "[OK] 节点1 转向完成 实际:右转 (偏航:0.0->70.0)\r\n"
    wireless_uart_send_string(...)
```

**路口1完成!** `std_yaw=90°`, 车辆已右转约90°。

## 路口2: TURN_LEFT (左转)

### 检测 (NODE_NONE)

```
find_guaidian(): 左边线突变 → l_guaidian != 0
find_rect_path(): path_count = 3

plan_turn():
    index = 1 % 12 = 1
    planned = path[1] = TURN_LEFT
    if(TURN_LEFT && path_info.left_exist) ✓
    return TURN_LEFT

node_count++ → 2
node_state = NODE_DETECTED
```

### 锁定 (NODE_DETECTED)

```
turn_dir == TURN_LEFT:
    std_yaw -= 90.0f                    // 90° → 0°
    yaw_target = 0°
    yaw_before_turn = yaw_total ≈ 90°
    yaw_locked = 1
    node_state = NODE_TURNING
```

### 执行左转 (NODE_TURNING)

```
turn_dir == TURN_LEFT → bias_left(bin_image):
    guaidian_row = l_guaidian             // 例如=75
    change_line(0, 75, 0, 0):
        for i = 0 to 75:
            mid_line[i] = 0               // ★ 中线=最左侧
            l_border[i] = 0
            r_border[i] = 0
```

### 左转控制链

```
image_err ≈ -45 (大负值)
steer_pwm_out = (-45*20) - (gyro_z*30/100) ≈ -900

l_speed_output = 1200 + (-900) = 300     // 左轮(内侧)减速
r_speed_output = 1200 - (-900) = 2100    // 右轮(外侧)加速
motor_proc(300, 2100) → 差速左转

yaw_total: 90° → 80° → ... → 20°
```

### 完成判定

```
if(yaw_total <= yaw_target + 20°):        // 0 + 20 = 20°
    yaw_total ≤ 20° ✓

delta_yaw = 20° - 90° = -70°
if(delta_yaw < -30°) → actual_turn_dir = TURN_LEFT ✓
turn_verify_flag = 1
node_reset_state()

无线上报:
    "总节点:12 | 当前:2 | 规划:左转"
    "[OK] 节点2 转向完成 实际:左转 (偏航:90.0->20.0)"
```

**路口2完成!** `std_yaw=0°`

## 路口3: TURN_RIGHT (右转)

### 检测与规划

```
find_guaidian(): 右边线突变 → r_guaidian != 0
find_rect_path(): path_count = 3

plan_turn():
    index = 2 % 12 = 2
    planned = path[2] = TURN_RIGHT
    right_exist ✓ → return TURN_RIGHT

node_count++ → 3
```

### 锁定

```
std_yaw += 90°                          // 0° → 90°
yaw_target = 90°
yaw_before_turn ≈ 0°
```

### 执行

```
bias_right() → change_line(187, guaidian_row, 187, 0)
    中线偏移到最右侧

image_err → 大正值 → steer_pwm_out → 正值
l_speed = 1200 + 正值 (外侧快)
r_speed = 1200 - 正值 (内侧慢)
motor_proc(大, 小) → 右转

yaw_total: 0° → 10° → ... → 70°
```

### 完成

```
yaw_total >= 90° - 20° = 70° ✓
delta_yaw = 70° - 0° = 70° > 30° → actual = RIGHT ✓
turn_verify_flag = 1
std_yaw = 90°
```
