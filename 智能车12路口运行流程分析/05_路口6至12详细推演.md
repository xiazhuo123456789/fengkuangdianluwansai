## 路口9: GO_STRAIGHT (直行) — 特殊处理

这是路径中第一个直行路口,处理逻辑与转弯完全不同。

### 检测与规划

```
find_guaidian(): 检测到拐点(路口处边线突变)
find_rect_path(): path_count >= 3

plan_turn():
    index = 8 % 12 = 8
    planned = path[8] = GO_STRAIGHT
    if(GO_STRAIGHT && path_info.top_exist) ✓
    return GO_STRAIGHT

node_count++ → 9
```

### 锁定

```
turn_dir == GO_STRAIGHT:
    yaw_target = std_yaw = 0°            // ★ 目标偏航不变
    // std_yaw 不增不减
    yaw_before_turn = yaw_total ≈ 0°
    yaw_locked = 1
    node_state = NODE_TURNING
```

### 直行通过 (NODE_TURNING特殊逻辑)

代码位置: image.c:652-688

```
NODE_TURNING → GO_STRAIGHT:
│
├── static float start_dist = 0.0f       // 静态变量,记录起始里程
├── static uint8 started = 0             // 静态变量,开始标志
│
├── ★ 记录起始里程:
│   if(!started):
│       start_dist = total_dist           // 例如=0.50m
│       started = 1
│
├── ★ 等待行驶超过0.25米:
│   if(total_dist - start_dist > 0.25f):
│   │   // 例如 total_dist=0.76m, 差值=0.26m > 0.25 ✓
│   │
│   └── ★ 检测路口是否已过:
│       if(find_rect_path(bin_image) < 3):
│       │   // 路口已过,图像中不再是T字/十字
│       │
│       ├── yaw_after_turn = yaw_total    // ≈ 0°
│       ├── delta_yaw = 0° - 0° = 0°
│       │
│       ├── ★ 校验实际方向:
│       │   if(delta_yaw < -30°):          否
│       │   if(delta_yaw > 30°):           否
│       │   else:
│       │       actual_turn_dir = GO_STRAIGHT   // 实际=直行
│       │
│       ├── ★ 转向校验:
│       │   if(actual_turn_dir == turn_dir):    // STRAIGHT==STRAIGHT ✓
│       │       turn_verify_flag = 1            // 校验通过
│       │
│       ├── node_reset_state() → node_state = NODE_NONE
│       │
│       └── started = 0                   // 重置静态变量
```

### 直行期间的控制

```
// 整个直行过程中不调用bias_left/bias_right
// 中线保持正常循迹位置

image_err ≈ 0 (正常循迹,中线居中)
steer_pwm_out ≈ 0
l_speed_output ≈ 1200
r_speed_output ≈ 1200
motor_proc(1200, 1200) → 两轮同速直行

yaw_total 基本不变 (直行无旋转)
total_dist 持续增加
```

### 与转弯的关键区别

| 对比项 | 转弯(LEFT/RIGHT) | 直行(STRAIGHT) |
|--------|-------------------|----------------|
| 偏置函数 | 调用bias_left/bias_right | 不调用任何偏置 |
| 完成条件 | yaw_total达到目标阈值 | 行驶>0.25m且路径<3 |
| std_yaw | 增减90° | 不变 |
| 中线 | 被强制偏置到边缘 | 保持正常循迹 |
