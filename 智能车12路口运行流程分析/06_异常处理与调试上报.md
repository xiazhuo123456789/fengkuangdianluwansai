# 异常处理与调试上报

## 一、路径规划异常处理

### 1.1 plan_turn() 的验证逻辑 (image.c:535)

正常情况下,`plan_turn()` 会验证规划方向在图像中是否存在:

```
plan_turn():
    index = node_count % path_len
    planned = path[index]
    plan_warn_flag = 0                    // 默认无警告

    // 验证路径是否存在
    if(planned == TURN_LEFT && path_info.left_exist):
        return TURN_LEFT                  // 左转且左边有路 → OK
    if(planned == TURN_RIGHT && path_info.right_exist):
        return TURN_RIGHT                 // 右转且右边有路 → OK
    if(planned == GO_STRAIGHT && path_info.top_exist):
        return GO_STRAIGHT                // 直行且前方有路 → OK

    // ★ 如果执行到这里: 规划方向在图像中不存在
    plan_warn_flag = 1                    // 设置警告标志
    return planned                        // 仍然返回规划方向(强制执行)
```

### 1.2 警告场景举例

假设路口1规划为TURN_RIGHT,但图像中只检测到左边有路(right_exist=0):

```
plan_turn():
    planned = TURN_RIGHT
    if(TURN_RIGHT && right_exist=0):      // ✗ 不匹配
    if(GO_STRAIGHT && top_exist):         // 检查其他方向...
    // 全部不匹配
    plan_warn_flag = 1                    // ★ 警告!
    return TURN_RIGHT                     // 仍然执行右转
```

### 1.3 警告的影响

- `plan_warn_flag = 1` 本身不阻止转向执行
- 仅用于无线调试上报,提醒操作者图像检测可能有误
- 车辆仍按规划方向转向,可能导致冲出赛道

## 二、转向校验机制

### 2.1 校验原理

每次转向完成后,通过陀螺仪测量实际偏航角变化,与规划方向对比:

```
转向完成后:
    yaw_after_turn = yaw_total
    delta_yaw = yaw_after_turn - yaw_before_turn

    if(delta_yaw < -30°):
        actual_turn_dir = TURN_LEFT       // 实际左转了
    else if(delta_yaw > 30°):
        actual_turn_dir = TURN_RIGHT      // 实际右转了
    else:
        actual_turn_dir = GO_STRAIGHT     // 实际直行了

    if(actual_turn_dir == turn_dir):
        turn_verify_flag = 1              // ✓ 匹配
    else:
        turn_verify_flag = 2              // ✗ 不匹配!
```

### 2.2 校验失败的场景

| 规划方向 | 实际偏航变化 | actual_turn_dir | turn_verify_flag |
|----------|-------------|-----------------|------------------|
| TURN_RIGHT | delta_yaw=+70° | TURN_RIGHT | 1 (匹配) |
| TURN_RIGHT | delta_yaw=-30° | TURN_LEFT | 2 (不匹配!) |
| TURN_LEFT | delta_yaw=-70° | TURN_LEFT | 1 (匹配) |
| TURN_LEFT | delta_yaw=+10° | GO_STRAIGHT | 2 (不匹配!) |
| GO_STRAIGHT | delta_yaw=0° | GO_STRAIGHT | 1 (匹配) |
| GO_STRAIGHT | delta_yaw=+50° | TURN_RIGHT | 2 (不匹配!) |

## 三、node_proc() 中的 reset 处理 (image.c:587)

```
node_proc():
    static float yaw_target
    static uint8 yaw_locked
    static uint8 cur_paths

    if(node_reset):                       // 外部触发的重置
        yaw_target = 0.0f
        yaw_locked = 0
        cur_paths = 0
        node_reset = 0                    // 清除重置标志
        return                            // 直接返回,不执行后续逻辑
```

当 `reset_all()` 被调用(按键1/2/3)时,`node_reset=1` 会通知 `node_proc()` 重置其内部静态变量。

### 4.1 wireless_uart_proc() 功能

该函数在主循环的 `debug_proc()` 中调用,提供两大功能:

#### 功能1: 接收控制命令

```
wireless_uart_read_buffer(data_buffer, 32):
    if data_buffer[0]=='r': run_flag = 1     // 远程发车
    if data_buffer[0]=='s': run_flag = 0     // 远程停车
    if data_buffer[0]=='t' && [1]==':':      // 设置阈值
        threshold = strtod(data_string)
```

#### 功能2: 节点状态上报

```
static uint8 last_node_count = 0
static uint8 last_verify_flag = 0

// 当node_count变化且>0时上报
if(node_count != last_node_count && node_count > 0):
    // 查询当前路口的规划方向
    cur_index = (node_count - 1) % path_len
    switch(path[cur_index]):
        TURN_LEFT   → plan_str = "左转"
        TURN_RIGHT  → plan_str = "右转"
        GO_STRAIGHT → plan_str = "直行"

    // 如果有规划警告,先发警告
    if(plan_warn_flag):
        sprintf → "[!警告] 节点%d 规划:%s 但图像中未检测到该方向路径!"
        wireless_uart_send_string(...)

    // 发送节点信息
    sprintf → "总节点:%d | 当前:%d | 规划:%s"
    wireless_uart_send_string(...)

    last_node_count = node_count
    last_verify_flag = 0                  // 等待转向完成
```

#### 功能3: 转向校验上报

```
// 当turn_verify_flag变化且!=0时上报
if(turn_verify_flag != 0 && last_verify_flag == 0):

    // 查询实际转向方向
    switch(actual_turn_dir):
        TURN_LEFT   → actual_str = "左转"
        TURN_RIGHT  → actual_str = "右转"
        GO_STRAIGHT → actual_str = "直行"

    if(turn_verify_flag == 1):
        // 匹配
        sprintf → "[OK] 节点%d 转向完成 实际:%s (偏航:%.1f->%.1f)"

    else if(turn_verify_flag == 2):
        // 不匹配!
        sprintf → "[!!!错误] 节点%d 规划:%s 实际:%s (偏航:%.1f->%.1f)"

    wireless_uart_send_string(...)
    last_verify_flag = turn_verify_flag
    turn_verify_flag = 0                  // 清除标志
```

## 五、直行路口的退出条件详解 (image.c:652-688)

GO_STRAIGHT 的退出需要同时满足两个条件:

```
条件1: total_dist - start_dist > 0.25f
       // 行驶距离超过0.25米
       // 防止刚进入路口就误判退出

条件2: find_rect_path(bin_image) < 3
       // 矩形框内检测到的路径数少于3
       // 说明已经驶过路口,不再是T字/十字
```

两个条件缺一不可:
- 只满足条件1不满足条件2: 还在路口中,继续直行
- 只满足条件2不满足条件1: 刚进入路口,可能是误检,继续等待
- 两个都满足: 确认已通过路口,退出转向状态

## 六、find_rect_path() 检测逻辑详解 (image.c:394)

### 6.1 矩形框定义

```
RECT_LEFT   = 18      // 左边界col
RECT_RIGHT  = 170     // 右边界col
RECT_TOP    = 20      // 上边界row
RECT_BOTTOM = 100     // 下边界row
```

矩形框覆盖图像中心区域,用于检测赛道分叉。

### 6.2 四条边的检测

```
上边(row=20): 从col=18到168扫描 黑→白→白 跳变 → top_exist
下边(row=100): 从col=18到168扫描 黑→白→白 跳变 → bottom_exist
左边(col=18): 从row=20到98扫描 黑→白→白 跳变 → left_exist
右边(col=170): 从row=20到98扫描 黑→白→白 跳变 → right_exist
```

### 6.3 路径数与路口类型

| path_count | 路口类型 | 说明 |
|------------|----------|------|
| 0 | 无赛道 | 图像异常 |
| 1 | 死胡同 | 极少出现 |
| 2 | 直角弯 | 只有两个方向有赛道 |
| 3 | T字路口 | 三个方向有赛道 |
| 4 | 十字路口 | 四个方向都有赛道 |

### 6.4 直角弯 vs T字路口的处理差异

```
if(path_count == 2):                      // 直角弯
    turn_dir = corner_turn()              // ★ 使用corner_turn()
    // 不增加node_count
    // 不使用路径规划

if(path_count >= 3):                      // T字或十字
    turn_dir = plan_turn()                // ★ 使用plan_turn()
    node_count++                          // 增加路口计数
    // 使用路径规划数组
```

### 6.5 corner_turn() 逻辑 (image.c:558)

```
corner_turn():
    // 下方+左边有路,右边无路 → 左转
    if(bottom_exist && left_exist && !right_exist):
        return TURN_LEFT

    // 下方+右边有路,左边无路 → 右转
    if(bottom_exist && right_exist && !left_exist):
        return TURN_RIGHT

    return TURN_NONE                      // 无法判断
```

## 七、拐点检测 find_guaidian() 详解 (image.c:321)

```
find_guaidian(start, end):
    l_guaidian = 0                        // 清零
    r_guaidian = 0

    // 确保start > end (从下往上扫描)
    if(start < end): swap(start, end)

    // 边界保护
    if(start >= ROW-1-5): start = 114     // 防止i-5越界
    if(end <= 5): end = 5                 // 防止i-5越界

    for i = start down to end:
        // 左拐点: 左边线在5行内跳变>=50像素
        if(l_guaidian==0 && abs(l_border[i]-l_border[i-5])>=50):
            l_guaidian = i

        // 右拐点: 右边线在5行内跳变>=50像素
        if(r_guaidian==0 && abs(r_border[i]-r_border[i-5])>=50):
            r_guaidian = i

        // 两个都找到就提前退出
        if(l_guaidian!=0 && r_guaidian!=0):
            break
```

| NODE_TURNING | find_guaidian(115, 30) | row 30~115 | 转向时偏置起点 |
