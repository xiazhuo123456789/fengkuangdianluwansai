# 超时停车与全局状态表

## 一、超时停车逻辑

### 1.1 RUN_TIME 定义 (init.h:16)

```
#define RUN_TIME  15                      // 运行时间=15秒
```

### 1.2 停车时间线

```
10ms中断 → run_time_proc():

    timer_1s == 15 (第15秒):
        run_flag = 0                      // ★ 停止运行

    timer_1s == 16 (第16秒):
        fuya_flag = 0                     // 关闭蜂鸣器
        start_flag = 0                    // 重置启动标志
        timer_1s = 0                      // 重置秒计数器
        cnt_10ms = 0                      // 重置10ms计数器
```

### 1.3 停车后的系统状态

```
run_flag = 0 后:

1ms中断 → control_proc():
    run_flag == 0:
        motor_proc(0, 0)                  // 两轮电机输出0
            左轮: PWM=0, 停止
            右轮: PWM=0, 停止

主循环继续运行:
    image_proc()                          // 摄像头继续采集
    debug_proc()                          // 调试通信继续
    屏幕继续显示图像

等待用户再次按下KEY4:
    start_flag = 1 → 重新开始倒计时 → 发车
```

## 四、完整时间线

```
T=0s      用户按下KEY4
T=0~1s    等待(蜂鸣器准备)
T=1s      蜂鸣器响(fuya_flag=1)
T=2s      车辆启动(run_flag=1)
T=2~15s   正常行驶,依次通过12个路口
          路口1(右)→路口2(左)→路口3(右)→路口4(右)→路口5(右)
          →路口6(左)→路口7(左)→路口8(左)→路口9(直)→路口10(右)
          →路口11(直)→路口12(直)
T=15s     停止运行(run_flag=0)
T=16s     完全停止(蜂鸣器关,标志重置)
T>16s     回到待机状态,等待再次按KEY4
```
